## 用户整体检查清单

### 尺寸与间距

- [ ] 桌面检查 36px 创建／取消与开始／取消、32px 添加实例与发送／停止、24px 图片移除，以及菜单、字段、设置和代码操作区。
- [ ] 检查主题、背景、语言与通知的统一紧凑选项；桌面侧栏宽度为 240px／260px，实例进度条底色铺满内容区，填充长度表示真实用量。
- [ ] 检查顶部栏、侧栏条目、输入区、回复标题与正文间距；消息时间可独立查看，展开与历史加载继续保持阅读位置。
- [ ] 手机与触摸设备检查 44px 操作区域，图片移除与消息时间的独立触摸范围、相邻入口间距及 Safe Area；窄窗口中的鼠标操作保持紧凑规格。

建议使用一个包含长正文、代码、表格、图片、Mermaid、thinking、多个工具与系统摘要的 session。操作涉及新建、切换或压缩时，使用允许这些操作的测试实例。

### 主题、语言与布局

- [ ] 分别查看 `mist`、`aurora`、`ember` 的亮暗模式，确认渐变可见、正文清晰，选中、危险、错误与禁用状态容易辨认。
- [ ] 查看桌面、窄窗口和手机；长实例名、目录与 Git branch 保持可读，侧栏列表独立滚动，顶部栏与正文阅读宽度正常。
- [ ] 切换中文与英文，检查长标签、菜单选项、表单按钮与设置行；刷新后语言和主题偏好保持选择。

### 长对话、分页与实时更新

- [ ] 从对话底部向上浏览并加载历史，确认当前阅读位置保持稳定；回到底部后，新消息继续跟随。
- [ ] 分别展开 thinking、执行汇总和整组回复；后续输出、工具结果与历史追加保持选择和阅读位置。
- [ ] 确认工具汇总 A → 正文 A → 工具汇总 B → 正文 B 的顺序，检查部分输出、最终结果、错误、终止、未知状态与真实时间／耗时。
- [ ] 运行期间刷新或重新连接，再切换实例与 session，确认历史恢复、工具状态和输入草稿符合预期。

### 输入、表单与手机键盘

- [ ] 验证多行输入、IME、Enter／Shift+Enter、图片上传／粘贴／移除、重新编辑、发送和停止；图片压缩与系统文件选择由实际浏览器检查。
- [ ] 在宽、窄输入区域选择模型、thinking、上下文和更多选项，确认发送／停止始终可操作；压缩后暂缺 tokens 时显示等待更新。
- [ ] 新建实例时选择 Edge、输入目录并使用补全；检查创建中、失败和无可用 Edge。压缩时提交自定义提示并检查失败反馈。
- [ ] 手机中显示、关闭键盘并改变屏幕方向，检查输入区、表单、菜单、详情窗口和 Safe Area；表单正文滚动，底部操作区保持可见。

### 详情、预览与浮层

- [ ] 桌面和手机快速打开／关闭／重新打开详情，检查动画方向、标题、滚动范围、Esc、Tab、Shift+Tab、背景交互限制和入口焦点恢复。
- [ ] 手机从顶部区域下滑关闭详情，同时检查正文滚动、代码横向滚动、文本选择与取消拖动。
- [ ] 从详情进入图片或 Mermaid 预览，切换原始尺寸与主题，关闭后返回详情；两层窗口均保持阅读位置。
- [ ] 打开 session、模型、thinking 与实例右键／长按菜单，检查搜索、分页、当前项、窄屏位置、滚动和关闭后的焦点。
- [ ] 在详情打开期间查看多条和长文本 Toast，检查等级、可见范围、持续时间与 Safe Area；复制操作同时确认浏览器 Clipboard 权限。

### 减少动态效果与运行性能

- [ ] 开启系统减少动态效果，检查背景、加载提示、折叠、弹层与通知；文字、状态和关闭操作完整可用。
